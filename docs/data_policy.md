# 데이터 이용 원칙

이 프로젝트는 비상업 개인 학습용입니다. 약관 해석은 법률 자문이 아니므로, 애매하면 사용 전에 확인하세요.

## TI 자료 (데이터시트·에라타·앱노트·E2E 포럼)

- TI 이용약관은 비상업·개인 용도의 다운로드를 허용하지만, 봇·스크래핑·데이터 마이닝 같은 자동 수집은 금지합니다.
- 그래서 문서는 **필요한 부품만 직접 내려받아** `data/raw/docs/`에 두고, 깃에는 올리지 않습니다 (`.gitignore` 처리됨).
- E2E 포럼은 크롤링하지 않습니다. 사람이 읽고 **증상·원인·해결을 자기 말로 요약한 사례 카드**를 만들고 원문 링크만 남깁니다.
- TI 제품 정보 API는 승인된 회사 계정만 쓸 수 있어 사용하지 않습니다. 필요한 사양은 데이터시트에서 부품 카드로 옮깁니다.

## 공개 Q&A (EE Stack Exchange)

- 콘텐츠는 CC BY-SA 4.0입니다. 쓰면 출처(글 링크·작성자)를 표기합니다.
- 2024년 7월 이후 새 덤프는 로그인하고 'LLM 학습에 쓰지 않는다'에 동의해야 받을 수 있습니다.
  이 프로젝트는 검색·평가에만 쓰고 모델 학습에는 쓰지 않습니다.

## 샘플 데이터

- `data/samples`, `data/parts`, `data/cases`, `data/eval`의 `EXAMPLE-*` 부품과 문서는 데모용으로 직접 만든 **가상 데이터**입니다.
- 실제 부품 데이터를 추가할 때는 부품 카드의 `source`에 데이터시트 이름과 페이지를 적어, 답변의 근거로 인용되게 합니다.

## 개인정보

- 실제 고객 이름·연락처는 넣지 않습니다. 평가셋과 사례 카드는 가상 고객명을 씁니다.
